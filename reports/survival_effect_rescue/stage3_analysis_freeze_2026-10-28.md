## 0. Question and claim boundary

When a feature's activation pattern is better preserved by quantization (higher R1), is the effect of an intervention on that feature also better preserved (higher W1) **beyond what simple baselines already predict**? A positive answer is **predictive evidence** for this model, layer, SAE, data (FLORES dev set) and these simulated weight-only quantizers; it is not a mechanism, not generalization, and not independent validation (R1 and W1 come from the same perturbed model and share contexts). A null answer is an acceptable result.

## 1. Units, populations, strata (all fixed here)

- **Unit:** one SAE feature; 1,487 features in 27 languages (`feat_lang`), one row per feature per state; no feature has two rows. **Clusters:** the 27 languages (contexts and sentences are shared inside a language).
- **Cells (analysed separately, no pooling before the cell results):** arm in {legacy RTN, matched RTN, GPTQ} x bit width in {INT6, INT4} = 6 cells. Full precision is the reference, INT16 is the numerical-noise reference (the legacy rounding, identical in all arms: `legacy_f5_a`).
- **Outcome:** W1 = `write.cos` (cosine of the single-feature effect fingerprints in full precision and in the quantized state).
- **Primary population (reliable fingerprints):** features whose own fingerprint is reproducible at the rounding-noise level, i.e. INT16 `cos` >= the committed numerical floor 0.94888916015625 (F5 `floor.tau`, the 5th percentile of the FP-versus-INT16 cosine). This is the rule for "a feature whose effect cannot be judged like a clear one": it uses ONLY the INT16 reference, never INT6 or INT4 outcomes. Expected about 1,412 of 1,487; the exact count is reported. The other features are reported as a separate noisy-effect stratum (counts and the same statistics, labelled, not pooled into the primary result).
- **Sensitivity populations (only these two, no others):** (S-all) all 1,487 features; (S-loss) features with a clear full-precision loss effect, |dnll_FP| >= 0.0014654942796007557 (the 95th percentile of |dnll_INT16 - dnll_FP| over the 1,487 features, again from the noise reference only; 842 features have |dnll_FP| above it, 645 below).
- **Join audit (done before this freeze, no outcome read):** stage-A `feat_ids`, `feat_lang`, `write_features`, `contexts` equal in legacy, matched RTN and GPTQ; 1,487 distinct ids (0 to 16,383 range); the F5 language list and the Phase 1 `survival.pt` language list are identical in content and order; for every (native language, feature) pair the Phase 1 `mean_activation`, `max_activation` and `firing_rate` are non-zero and not NaN (n = 1,487); all 1,487 features are flagged selective in Phase 1 `selectivity.pt`; no NaN in `corr`, `cos`, `dnll` in any state; the only missing value is one `scale` in the legacy INT4 file (handled in section 2).

## 2. Predictors and baselines (no combined score invented after the fact)

- **Primary predictor:** R1 = `read.corr` of the state (continuous). Secondary predictors: `read.jaccard` (firing-set overlap) and the scale deviation |`read.scale` - 1| (a missing value is replaced by the training-fold median and counted). The binary label R1 > 0.9 is a **labelled secondary dichotomy** (reported as a 2x2 and an AUROC for W1 >= floor), with no other cutoffs.
- **Baselines (model A):** (a) number of active dev sentences `n_active` (stage A); (b) Phase 1 native-language firing rate; (c) Phase 1 native-language mean activation; (d) |dnll| of the full-precision ablation (FP state file); (e) number of ablated positions `n_pos` (FP state file). Phase 1 values: the equal-budget `eq` run of the legacy arm (identical in all three arms; checked), indexed by (F5 `feat_lang`, `feat_ids`); the corpus differs from the F5 dev tokens (FLORES devtest tokens in Phase 1), which is stated wherever it matters.
- **Models:** A = (a) to (e); B = A + R1; C = B + jaccard + scale deviation (secondary); R1-only (descriptive); null = the training-fold median of W1.
- **Preprocessing:** every predictor is replaced by its rank-based quantile (empirical CDF of the TRAINING fold, applied to the test fold by interpolation); the target W1 stays on its raw scale (no transformation of W1).

## 3. Estimators, validation and uncertainty

- **Association (descriptive, per cell and population):** Spearman rho of R1 with W1; partial Spearman of R1 with W1 given A (residuals of the ranks of R1 and of W1 after a least-squares fit on the ranks of A with intercept, then Pearson correlation of the residuals); 95 % intervals by a language-cluster bootstrap (resample the 27 languages with replacement, recompute everything), 2,000 replicates, seed 20261028.
- **Prediction (the decision quantity):** leave-one-language-out: for each of the 27 languages, fit on the other 26 languages' features, predict the held-out language's features. **Ridge regression** with penalty lambda chosen from {0.01, 0.1, 1, 10, 100} by 5-fold cross-validation grouped by language inside the training set (minimum MAE; ties go to the larger lambda); the final fit uses all training features. Held-out mean absolute error (MAE) of W1 pooled over all features, for null, A, B, C. **Improvement of B over A = 1 - MAE_B / MAE_A**; interval by the same language-cluster bootstrap applied to the per-language sums of held-out absolute errors (2,000 replicates, seed 20261028; a paired difference, since both models predict the same features). Same for C over B (secondary) and A over null (descriptive).
- **Deviation from the addendum, recorded:** the addendum's model A includes margin, gradient scalars and generic sensitivity; these do not exist for F5, so A is limited to (a) to (e) above. The 10 % project target and the A / B / C structure are unchanged.

## 4. Decision rules (fixed before the analysis; project targets, not universal thresholds)

- **Per cell (primary population):** survival "adds predictive value beyond baselines" iff the improvement of B over A is >= 10 % AND the lower end of its 95 % interval is > 0. The partial Spearman interval excluding 0 is the secondary check.
- **Overall statement:** "adds predictive value" only if the per-cell condition holds in all 6 cells; "mixed" if it holds in 1 to 5 cells; "no clear predictive value beyond baselines" if in none. No result is pooled across arms or bit widths to rescue a verdict. A cell where the held-out MAE of A already equals the null (no baseline predictive value) is reported as such.
- **Stop rule:** if the overall statement is "no clear predictive value", report that and stop: no cutoff tuning, no extra predictors, no broader sweep, no switch to steering.
- **Labels:** every result of this analysis is labelled post hoc and exploratory; the sensitivity populations and the C-over-B result are secondary and cannot change the primary statement.

3. **Outputs generated from files:** the report (Stage 4) reads its numbers from the result JSON and a test compares the written statements with it.

## 6. What cannot be done and is not claimed

No margins (not saved); no read-side document ids (document-level independence is not claimed); the fingerprints and the sufficient statistics behind R1 are not saved (the reproduction starts at the per-feature values); no external-panel F5 exists (plan Stage 3 step 7 is unavailable, not substituted by group-level scores); one model, layer, SAE and the three simulated weight-only quantizers; the sample of 1,487 features is stratified, not random, so no population statement about all features; R1 and W1 share a cause (the same perturbed model), so no causal reading.
