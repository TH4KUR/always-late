## What the study leaves open

1. The loss of association could reflect the model, the frozen dictionary, or a generic sensitivity of near-ties to any perturbation. The data point to the last at the high widths (loss concentrates in features with a small baseline margin; INT16/INT12 already lose 0.7 %), and to scale effects at INT4 (activation scale and firing rate relate to loss).
2. Nothing was measured about function: whether lost features still do what they did (ablation, steering), or whether retained ones still do.
3. The frozen SAE's own fidelity under quantization, by language and width, was not measured (reconstruction error, active-feature counts, residual scale): candidates M2 and Q15 (D-034).
4. Results are exploratory on already examined FLORES data; the cohort is English-heavy (1,719 of 8,086 features).

## Selected order and scope (Q16, D-039)

1. **Closer analysis of existing data (A):** quantify weak-peak and scale associations within languages, report English-excluded/macro-language views and numerical-floor comparisons, and audit the shifted bootstrap intervals before using them for inferential claims. These are associations, not identified mechanisms.
2. **SAE fidelity (B):** design the measurement checks alongside the functional experiment; use them to diagnose intervention/reconstruction artifacts and interpret results, not as standalone proof of language-function preservation.
3. **Functional validation (C):** selected, rather than deferred until there is spare time. Start with a bounded full-precision pilot to establish task competence, clean/corrupt contrast and intervention validity, then apply the same defined experiment across the entire precision ladder.
4. **Tables/figures (F):** prepare alongside the selected analyses. This describes work order, not permission to spawn agents or start another chat. **D/E remain unselected.**

## Selected functional-study direction (D-039)

**Question:** Do the features identified by language association contribute to multilingual task performance specifically in their associated language, and is the direction and magnitude of that contribution preserved after quantization?

**What would count as evidence.** For example, disrupting Hindi-associated features should change Hindi task outcomes more than comparable other-language outcomes and matched control-feature interventions; patching suitable clean feature values into a corrupted run may recover relevant performance. Evaluate both disruption and recovery because they answer different questions and redundancy can hide an ablation effect. A gain on every language could reflect general task support; inducing Hindi output can reflect language control without better Hindi answers. Report task correctness and output-language compliance separately. No single intervention is a binary certificate that a feature is exclusively language-selective, and a null effect does not establish irrelevance outside the tested task/prompt distribution.

**Compare all six precisions.** Use FP and INT8/7/6/5/4 with the same fixed model/SAE feature identities, semantic task items, intervention site and feature groups. Keep the 27-language panel for existing-data/fidelity analyses; explicitly design and justify task/language coverage for the more expensive functional study, including target and off-target languages. Do not silently substitute a convenient language subset for a claim about all 27. Use fixed groups for the main precision curve; any condition-specific retained/lost regrouping is a separately labelled exploratory comparison, with baseline strength/selectivity/group-size matching rather than treating group differences as causal.

**Define the intervention, not just the word patching.** Choose task-grounded clean/corrupted prompt pairs and token alignment that isolate the hypothesised language function rather than merely changing answer content. The primary comparison uses each precision's own clean donor activations in its corrupted recipient run. Use disruptive resampling/ablation as a complementary check. FP-donor-to-quantized-recipient patching, if included, is a separate rescue experiment, not evidence that the quantized model natively retained that function. Feature edits should change only selected decoder contributions while preserving the recipient residual/reconstruction-error component; replacing the whole residual with the SAE reconstruction introduces a separate intervention. Exact hooks and SAE scaling/decoder semantics must be verified before implementation.

**Magnitude and controls.** A fixed additive coefficient can be much stronger relative to a low-precision model's feature scale. Compare a predefined sweep of native replacement/interpolation strengths with a separately calibrated perturbation-norm-matched sensitivity, recording actual feature changes and residual perturbation norms. Fix calibration on separate data; do not tune each width for a favourable result. Include no-intervention, identity/self-patch, matched unrelated/nonselective-feature and other-language-feature controls; match feature-group size and relevant baseline firing/magnitude/decoder norms. Report remaining matching differences. Check SAE fidelity and reconstruction-only artifacts. These intervention controls are required within C; they are distinct from unselected D, a random perturbation of model weights.

**Outcomes and effect comparison.** For a higher-is-better task score define `effect[b] = score[b, intervention] - score[b, appropriate unintervened baseline]`, and compare `effect[b] - effect[FP]` on paired items. For clean-to-corrupted patching the baseline is the corrupted, unpatched run; for ablation it is the clean, unablated run. Report baseline scores as well as changes, task accuracy and a justified continuous measure such as answer log-probability/margin or cross-entropy with its sign stated. Include target-language versus off-target and matched-control effect contrasts with paired uncertainty. Compare effect direction, absolute size and prespecified dose-response curves; allow attenuation, amplification, reversal and no detectable effect. Quantized baselines can have different headroom, so any fraction-recovered score needs a non-negligible clean/corrupt gap and must be shown alongside raw changes. Define meaningful-change/equivalence margins prospectively if claiming similar effects; nonsignificance alone is not equivalence.

**Evaluation and execution boundary.** Freeze task choice, language coverage, group selection, corruptions, doses, metrics, meaningful-effect rules and uncertainty procedure before held-out task scoring. Separate calibration/pilot outcomes from evaluation; existing FLORES analyses stay exploratory. Do not reuse the association study's shifted threshold-bootstrap intervals without checking estimator suitability for the new score differences. The exact dataset, sample sizes, methods and compute remain design work: do not claim the old runtime estimate covers the expanded factorial experiment, and do not launch a large sweep before a tested, source-grounded pilot. This record applies Q16; it does not start code, jobs, scheduling or paper prose.

**Prior work.** P02 already studies language-specific SAE ablation/steering, so doing such an intervention is not itself new. P08 motivates task-grounded functional evaluation. [Zhang and Nanda, ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/06a52a54c8ee03cd86771136bc91eb1f-Abstract-Conference.html) shows that corruption and metric choices affect patching findings; [Heimersheim and Nanda, 2024 preprint](https://arxiv.org/html/2404.15255v1), sections 2.5-4, explains complementary disruptive/recovery tests, redundancy and prompt-distribution limits. See M06/M07 in [the source register](../research_sources.md). These motivate controls, not a validated result in our quantized multilingual setting; the exact closest-work/novelty check remains required before a publication claim.
