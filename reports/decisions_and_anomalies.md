# Decision log, anomaly register and source-verification queue (living document)

Rules for this project, restated: (1) when we replicate a paper we use **their code and setup**, and any deviation is a labelled diagnostic; (2) new code is a labelled, tested diff on their code and must reproduce the baseline when its new switches are off; (3) every choice below has a source or evidence; (4) every anomaly in the results is recorded here with its status, even when it is minor. Entries are never deleted: a changed mind is a new entry that references the old one. Paper prose is written by the team; this file is an engineering record.

Status words: **adopted** (in force), **proposed** (needs the user's / team's decision), **explained** (cause shown by an experiment), **hypothesis** (plausible cause, not tested), **open** (unexplained), **accepted** (judged harmless, reason given).

Last updated: 2026-10-17.
