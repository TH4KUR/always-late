\begin{abstract}
When a language model's weights are rounded to fewer bits, do the features used to explain it still behave in the same way? We study 27 languages, mainly with Gemma-2-2B and a fixed sparse autoencoder (SAE). We reproduce an earlier study and find that omitting the beginning-of-sequence token substantially changes its Gemma measurements. After correcting this input protocol, removing selected language features harms next-token prediction more than removing matched controls in all 27 languages. Gemma-2-9B shows the same broad pattern. Effects remain near full precision at six bits and grow at four bits under simple rounding; GPTQ reduces that change. Activation changes and output effects differ: under legacy RTN at four bits, only 13.2\% of a 1,487-feature sample passes the activation-survival cutoff, yet 99.7\% can still be identified from their effects. Activation correlation gives a small positive gain in predicting effect similarity. A reading-comprehension test shows no clear effect of the selected groups, and restoring their activations repairs little quantization loss. The study establishes useful effects of specific feature edits and shows why activation agreement, task performance and preservation of an edit's effect need separate measurements.
\end{abstract}

\section{Introduction}
Quantization rounds model weights to fewer allowed values. It can make language models cheaper to store and run, but may also change their behavior. The effects can differ across languages and tasks \citep{marchisio-etal-2024-quantization}. We investigate what happens to the internal features used to explain these models.

A sparse autoencoder (SAE) is a separate network that describes a model's hidden state using a few active features from a large learned dictionary. Each feature has an activation strength and a direction in the hidden state. Some activate more often for one language than for others. Previous work has identified and edited such language features \citep{deng-etal-2025-unveiling}; another study measures how their activations change under quantization \citep{duan2026}.

We connect these measurements. A changed activation does not immediately tell us whether removing that feature still has the same effect on the model. Likewise, a feature can matter for predicting the next token without producing a measurable change on a reading-comprehension test. We compare these outcomes directly.

Four questions organize the completed study:
\begin{description}
\item[RQ1:] Which language features retain their activation patterns after quantization, and how does the quantizer affect this?
\item[RQ2:] How does editing language features affect text prediction and comprehension before and after quantization?
\item[RQ3:] How well do activation measurements predict whether a feature's output effect is preserved?
\item[RQ4:] How much does the same feature edit change when the model is quantized, and what explains that change?
\end{description}
These final questions organize the accumulated evidence. They do not replace the original hypotheses or the choices fixed before each analysis.

\section{Related Work}
\paragraph{Compression and language.}
\citet{marchisio-etal-2024-quantization} show that multilingual quantization effects vary by task and evaluation. Resource tiers describe differences in language resources \citep{joshi-etal-2020-state}, but do not isolate how much training exposure a model received. GPTQ uses calibration data to reduce rounding error \citep{frantar2022}. We compare it with simple rounding under two implementations.

\paragraph{SAEs and direct evaluation.}
Gemma Scope supplies public SAEs for Gemma models \citep{lieberum-etal-2024-gemma}. JumpReLU and TopK provide ways to learn sparse representations \citep{rajamanoharan2024,gao2024}. These tools remain imperfect: features can mix concepts, split them across units, or leave parts of the hidden state unexplained \citep{leask2025canonical}. Task-based evaluation can still test whether specific edits are useful \citep{makelov2025principled}. SAEBench also shows that better proxy scores need not yield better practical performance \citep{karvonen2025saebench}. We therefore keep the dictionary fixed and measure both activations and controlled edit effects.

\paragraph{Feature preservation and patching.}
Language-feature editing predates our study \citep{deng-etal-2025-unveiling}. Related work studies activation survival under rounding \citep{duan2026}, geometric survival under pruning \citep{borobia2026}, and the geometry of feature effects \citep{hoang2026}. Activation patching can test where quantization error affects outputs \citep{chang-etal-2025-inputs}, including interactions between patches \citep{vaidyanathan2026}. Our contribution is to compare these kinds of preservation across languages and quantizers with explicit control edits. Belebele provides a separate comprehension task \citep{bandarkar-etal-2024-belebele}.

\section{Experimental Setup}
\paragraph{Models and data.}
The main model is Gemma-2-2B \citep{gemma2024}. Its fixed Gemma Scope JumpReLU SAE has 16,384 features and reads the hidden state after layer 12. Model inference uses bfloat16; SAE calculations and edits use float32. The Gemma-2-9B extension uses a layer-20, 16k SAE. A smaller Llama-3.2-1B study \citep{grattafiori2024} uses a layer-12 TopK SAE with 14,336 features and $k=48$. Model, SAE, training data and tokenizer change together in that comparison.

The main panel contains aligned FLORES-200 sentences \citep{nllb2022} in 27 languages, nine per descriptive resource tier. Feature selection uses the development split. Activation and language-association tests use 27,036 content tokens per language from devtest; prediction-loss tests use 300 aligned devtest sentences. The comprehension test uses 385 Belebele questions per language in 18 languages that passed calibration, grouped into 219 passage clusters. A second transfer panel uses fresh Wikipedia articles in six languages.

\paragraph{Quantization.}
Round-to-nearest (RTN) maps a weight to its nearest allowed value. Legacy RTN is the original implementation, which shares attention scales across corresponding coordinates of different heads. Matched RTN uses one scale per output channel and the same rounding grid as GPTQ. GPTQ calibrates on 8,192 Wikipedia tokens per language (221,184 total), separate from evaluated sentences and articles. Matching the grid helps distinguish changes in the rounding setup from GPTQ's additional benefit. Calibration and error compensation still change together.

Selected transformer weights are rounded; embeddings and normalization parameters stay unchanged. Values remain stored and evaluated in floating point, so we measure weight-rounding effects rather than deployment speed or memory savings. The original tests cover FP and eight to four bits (INT8--INT4). FP is the unquantized reference. Later intervention comparisons focus on INT6 and INT4. INT16 and INT12 make small real weight changes and serve as reference conditions; INT16 is not identical FP arithmetic.

\paragraph{Analysis status.}
Most FLORES studies are exploratory: they reuse examined sentences or follow earlier results. Fixing a later stage's choices before its output does not supply independent confirmation. The original held-out Belebele family is confirmatory. We claim no verified external preregistration. Code hashes, input records, restore checks and sham edits support implementation checks. New quantizer arms reproduce FP reference values exactly. The 9B review regenerates its analysis byte-identically from pinned raw files; it does not repeat GPU inference. This reporting revision adds no experiment or statistical analysis.

\section{Problems Found and Corrected}
\paragraph{The missing BOS token in the earlier Gemma evaluation.}
Our first reproduction disagreed with Duan's reported survival rates. Running their released code reproduced their table closely: INT7 survival was 81.19\% versus 81.26\%, and INT6 was 51.15\% versus 51.30\%. We traced the large disagreement to a methodological problem in their Gemma input protocol: it omitted the beginning-of-sequence (BOS) token.

Adding BOS to the same 256-content-token WikiText windows, while excluding its position from feature statistics, reduced full-precision perplexity from 458.4 to 16.1. Lower perplexity means better text prediction. INT6 survival rose to 97.52\%, and INT7 to 99.97\%. Each regime defines its own active-feature set, so these percentages do not follow exactly the same feature population. We corrected our subsequent protocol by prepending one BOS token and excluding BOS and padding from statistics and edits. This demonstrates a large input-protocol effect in the Gemma evaluation; it does not establish that every conclusion in Duan's paper is wrong.

\paragraph{Our own corrections.}
We retired the first pipeline after finding separate flaws, including counting BOS in feature statistics and changing tokens during decode/re-encode. Its results are excluded. We also corrected an assumption that INT16 was identical to FP: re-rounding makes a small real weight change. A small gain experiment had to be rerun on the intended GPU because the hardware shift was comparable to the measured effect. The 9B review found two defective prediction criteria, described with its results below. The full report and decision log retain these problems and their corrections.

\section{Measurements and Controls}
\paragraph{Feature activation and preferred language.}
A feature fires when its activation is positive. We select language features using the ratio of their highest per-language firing rate to their mean across languages. Selection also requires enough active tokens, a shuffled-language cutoff (50 permutations), and stable peak language in 80 of 100 resamples. This yields 8,086 features. On FP devtest, 6,663 have a unique supported peak language. We test retention of that language only for this established set.

Activation correlation instead compares the same feature's values on the same tokens before and after quantization:
\begin{equation}
 R_1=\operatorname{corr}_t(a_f^{\mathrm{FP}}(t),a_f^b(t)).
\end{equation}
The historical survival rule is $R_1>0.9$. Retaining a preferred language and retaining high correlation answer different questions.

\paragraph{Edits and prediction loss.}
Each language group contains its 64 selective features with the highest mean development-set activation, called K64. Control groups come from 2,860 supported nonselective features and match firing rate and mean activation on a log scale. Evaluation uses three control draws; the saved manifest stores up to five. Matching is close but imperfect: 75 of 81 language--size ratios fall within $[0.8,1.25]$, with Thai, Yoruba and Lao outside at K64.

For hidden state $x$, activation $a_f$ and decoder direction $d_f$, we edit a group $G$ as
\begin{equation}
 x'=x+\sum_{f\in G}(a'_f-a_f)d_f.
\end{equation}
This retains the SAE reconstruction error. Removal sets $a'_f=0$, scaling sets $a'_f=\alpha a_f$, and a donor patch uses the FP activation at the same position.

Prediction loss, or negative log-likelihood (NLL), measures how much probability the model assigns to the actual next token. Lower is better; units are nats/token. We subtract control-group harm from language-group harm and call the result excess harm, $E_\ell^b$. Positive $E$ means the language edit hurts more. The effect ratio $E_\ell^b/E_\ell^{\mathrm{FP}}$ compares it with FP: one means equal harm, 1.5 means 50\% greater harm. The median of language ratios, their mean, and the ratio of mean effects are reported separately because small denominators can make them differ. Patch recovery measures how much of the loss gap a specified restoration removes.

\paragraph{Output-effect similarity and uncertainty.}
A feature's effect fingerprint is the vector of changes in output-token scores caused by removing it. Cosine similarity with its FP fingerprint, $W_1$, measures how closely those directions agree; one means identical direction. The F5 study samples 1,487 features; 1,412 pass the INT16 reliability criterion. A stricter similarity cutoff, 0.9489, comes from the fifth percentile of INT16 cosines. Close agreement with this reference and recognizable feature identity are different tests.

Bracketed ranges are 95\% bootstrap intervals unless stated otherwise. Resampling units follow the experiment: paired sentences for group loss, passages for Belebele, languages for F5 prediction and reviewed 9B comparisons, and features plus source sentences for transfer. Intervals hold other choices, such as groups and controls, fixed. They do not describe uncertainty over all model or SAE choices.

\section{RQ1: Which Activations Survive?}
\paragraph{Feature activity changes the comparison.}
The original legacy-RTN tests did not establish a selective-feature disadvantage after Holm correction for multiple comparisons. Survival was lower than controls by 0.28 points at INT7 and 1.44 points at INT6 (adjusted $p=0.514,0.128$). Small effects remain possible. A stricter selectivity cutoff ($S>5$) gives a larger INT6 gap of $-7.16$ points; matching activation magnitude in ten bins reverses it to $+4.58$.

Low-, mid- and high-resource languages have INT6 survival rates of 69.4\%, 90.6\% and 95.1\%. Accounting for activation scale reduces the fitted tier slope from $+12.3$ to $-0.81$ points. Later measures still show some tier patterns at INT16, and GPTQ's adjusted result depends on the adjustment choice. These measurements alone do not identify a training-resource mechanism behind language damage.

\paragraph{GPTQ improves preservation.}
At INT6, average active-feature survival is 85.0\%, 89.7\% and 97.5\% for legacy RTN, matched RTN and GPTQ. At INT4, GPTQ exceeds legacy RTN by 17.83 points $[16.29,19.38]$ and matched RTN by 11.86 $[11.18,12.50]$. It also reduces the mean loss increase by 0.461 nats/token $[0.348,0.595]$ relative to legacy RTN. Both outcomes improve in all 27 languages. Intervals resample paired languages. Matched RTN closes part of the gap by itself. Its small selective-feature contrasts cross the significance threshold, while GPTQ's do not. These exploratory comparisons support a strong quantizer effect and no consistent selective penalty across all three methods.

\paragraph{Correlation misses some activation changes.}
Multiplying every activation by the same factor can leave correlation unchanged. We therefore decompose quantized activation as a scaled FP signal plus a residual: $b=ga+c+e$. Here $g$ is gain, $c$ is an offset, and $e$ is the part scaling does not explain. The residual is uncorrelated with $a$. Where the quantities are defined,
\begin{equation}
 \lambda=\log(R_1^{-2}-1)
 =\log\sigma_e^2-2\log|g|-2\log\sigma_a.
\end{equation}
The correlation cutoff 0.9 corresponds to $\lambda<-1.450$, with positive gain. We also measure pre-activation change divided by the feature's learned threshold, denoted $\nu$, on tokens active in FP. This puts the change in threshold units.

The audit covers 214,506 active language--feature pairs. It reproduces prior correlations within $3\times10^{-8}$ and checks the identity to about $10^{-14}$. Across six INT4/6 conditions, rank correlations with FP activation spread are $-0.507$ to $-0.534$ for $\lambda$, versus $-0.004$ to $0.114$ for $\nu$. Threshold scaling reduces this dependence, though dependence on peak activation remains. These measures explain different parts of activation change; the prediction test below asks whether they add useful information.

\section{RQ2: What Do Language-Feature Edits Change?}
\paragraph{Removing features harms next-token prediction.}
FP excess harm is positive in all 27 languages of Gemma-2-2B: mean 0.704 nats/token $[0.684,0.723]$, median 0.262. The effect stays near FP at INT6, then grows at INT4. Legacy INT4 has a median ratio of 1.54 $[1.43,1.62]$, a mean ratio of 2.14 $[2.04,2.50]$, and a ratio of mean effects of 1.33. GPTQ lowers the median to 1.22 $[1.14,1.24]$. Its mean ratio is 1.31 $[1.27,1.50]$, leaving its classification against the predefined $[0.75,1.33]$ band uncertain. Greater removal harm indicates greater sensitivity to the edit.

Gradual suppression supports the same result. In all 27 languages, FP harm increases as the activation multiplier decreases. Median harm is 0.0223, 0.0902, 0.1687 and 0.2624 at multipliers 0.354, 0.177, 0.088 and zero. The strict rule requiring monotonic change across every precision fails because of a small intermediate-width dip; the suppression-dose and consistency rules hold.

\paragraph{A second Gemma size and a different setup.}
Gemma-2-9B shows positive FP excess harm in all 27 languages, with median 0.270 $[0.197,0.608]$. The median effect ratio is 1.019 $[0.978,1.045]$ at INT6 and 1.586 $[1.238,2.264]$ at INT4. At INT4, the mean ratio is 2.479 and the ratio of mean effects is 1.474. These intervals resample languages. Paired 2B--9B difference intervals include zero, so the data support the broad pattern across sizes without resolving a size effect.

The 9B prediction checklist had two defects: its suppression inequality was reversed, and its selectivity criterion was guaranteed by how features were selected. We do not count those as independent confirmations. The measured suppression-harm ordering holds in all 27 languages. Gemma-2-9B GPTQ remains pending.

Llama has a smaller positive FP median effect, 0.048 $[0.018,0.173]$, with positive effects in 21 of 27 languages. This misses the consistency rule requiring 24. Its INT4 median ratio is 0.86 $[0.74,1.03]$, with less consistent suppression ordering. The effect differs across these model/SAE setups.

\paragraph{The comprehension effect is not established.}
On held-out Belebele, FP excess correct-option loss is $-0.0001$ nats/item $[-0.0035,+0.0031]$. Accuracy is about 42.6\% unedited, 42.6\% after language-group removal and 42.5\% after control removal. The required positive FP effect is absent, so the five planned conditional retention statements cannot be interpreted. Larger nonselective edits (1,024--2,860 features) lower accuracy by 1.2--2.2 points; other-language selective edits reach 6.0 points. Sham edits change nothing. GPTQ's INT4 baseline accuracy is 31.8\%, above 25\% chance, and the K64 effect remains small. The test detects larger edits but leaves small K64 effects possible.

\paragraph{Repair gains are limited.}
Restoring FP activations in K64 recovers 2.6\% $[2.4,2.8]$ of the legacy INT4 loss gap, versus 39.3\% $[38.5,40.0]$ for the full residual. GPTQ gives 2.0\% $[1.6,2.3]$ versus 41.4\% $[40.2,42.4]$. These are measured patch benefits, not additive shares of the cause of model damage.

The main fine-gain study fails its repair rules. A legacy-RTN follow-up on 562 fresh sentences finds a small benefit at multiplier 1.1: $-0.00135$ nats/token, with 97.5\% interval $[-0.00197,-0.00032]$, and improvement in 20 of 27 languages. It meets the rule after multiple-comparison correction at 1.1, but not 1.2. The primary pair of multipliers uses Holm correction. GPTQ does not repeat the fine-gain trend on the main 300-sentence panel; the fresh-sentence test was legacy-only.

Selecting groups anew after quantization changes their membership (overlap with FP falls from Jaccard 0.855 at INT6 to 0.488 at INT4), but does not make removal more harmful (median difference $-0.0098$). The most effective activation multiplier is repeatable within the study, yet does not track inverse activation shrinkage ($\rho=-0.17$, $p=0.804$). Simple shrinkage compensation is therefore not supported by this test.

\section{RQ3: Do Activation Measures Predict Output Effects?}
Of the 8,086 selected features, 6,663 establish a peak language on FP devtest. At legacy INT4, 70.8\% retain it, while only 13.75\% in this group pass activation correlation 0.9. Near-tied FP language preferences are more likely to switch: peak-margin discrimination scores are 0.90, 0.81 and 0.75 at INT6, INT5 and INT4. Removing matched lost-language and retained-language subgroups gives little harm difference: medians $+0.0006,+0.0007,+0.0002$ nats/token at INT4/5/6.

The individual-effect experiment shows that activation change can coexist with recognizable function. In the same 1,487-feature sample, only 13.2\% pass the activation cutoff at legacy INT4, but median output-effect cosine is 0.839 $[0.829,0.848]$. Most effects remain distinctive: 99.9\% exceed different-feature controls and 99.7\% identify their own FP feature. Only 0.3\% meet the stricter INT16-based similarity cutoff. GPTQ improves median cosine to 0.923 and raises the share passing that cutoff to 11.7\%. Keeping the same language label does not reliably identify which effects meet the preservation criterion; discrimination scores are near chance (legacy 0.506, GPTQ about 0.49).

Continuous activation correlation is more informative. On 1,412 reliable features, we predict effect similarity while holding out one language at a time. Adding correlation to activity, context-count and FP-effect-size predictors reduces mean absolute error by 3.1--4.4\% across all six quantizer/width conditions. Every language-bootstrap interval is above zero. At INT4, the gain is 3.7\% $[2.3,5.2]$ for legacy RTN and 3.5\% $[2.1,5.0]$ for GPTQ. These are small positive gains below the project's 10\% practical target. Partial rank correlations are 0.239--0.399.

Adding gain and threshold-scaled change $\nu$ after correlation gives further improvements of $-0.4$ to $+1.8$\%, with every interval including zero. The measures help describe activation changes without showing an additional prediction benefit. Llama's 610 reliable features show a similar INT4 gain, 4.2\% $[1.6,6.7]$, with partial correlation 0.252 $[0.184,0.322]$; INT6 is uncertain.

\section{RQ4: Does the Same Edit Still Have the Same Effect?}
\paragraph{Separating earlier context from later weights.}
We fix the edit direction and strength at their FP values. We then cross FP and quantized earlier layers with FP and quantized later layers. Let $D[p,s]$ be the resulting output-logit change, subtracting each condition's own unedited output. With Q denoting quantized,
\begin{align}
 C&=D[\mathrm{Q},\mathrm{FP}]-D[\mathrm{FP},\mathrm{FP}],\\
 W&=D[\mathrm{FP},\mathrm{Q}]-D[\mathrm{FP},\mathrm{FP}],\\
 I&=D[\mathrm{Q},\mathrm{Q}]-D[\mathrm{Q},\mathrm{FP}]\nonumber\\
  &\quad-D[\mathrm{FP},\mathrm{Q}]+D[\mathrm{FP},\mathrm{FP}].
\end{align}
$C$ measures the context contribution, $W$ the later-weight contribution and $I$ their interaction. The vectors add exactly; their lengths and medians do not. For groups, we compute the same crossed contrasts directly in prediction loss. A fifth condition uses the quantized model's own activation strength.

The panel has 404 features and 6,464 feature--context pairs. We retain 2,203 pairs from 235 features whose FP effects exceed five INT16 reference changes. A matched different-feature direction and three random directions with equal norm test sensitivity shared with other edits. Prediction holds out feature identities, while source sentences may occur in both splits.

At legacy INT4, median group excess harm is 0.848 nats/token for the fixed-strength edit, versus 0.263 in FP and 0.433 using native quantized strength. Median absolute context and weight terms are 0.310 and 0.104 nats/token. Native-minus-fixed harm is negative in every language, with median $-0.351$ $[-0.358,-0.293]$. The native-minus-weights-only remainder is smaller in the median language ($+0.0138$ $[0.0093,0.0233]$), with variation across languages. For individual output vectors, the weight term is larger. Attribution therefore depends on both the chosen edit and the outcome.

\paragraph{GPTQ transfers the edit more closely.}
At legacy INT6, output-effect cosine is 0.984 and relative error is 0.165, about 1.88 INT16 reference floors. At INT4, cosine is 0.768 $[0.760,0.776]$ and relative error 0.664. Matched RTN improves cosine to 0.822 and GPTQ to 0.877; relative error falls to 0.572 and 0.476. Lower relative error means the same edit gives a more similar output change.

Control directions also drift substantially. A later comparison matched FP effect size on 144 FLORES pairs and 107 Wikipedia pairs. Real-direction INT4 error norms are 1.14 $[1.07,1.25]$ and 1.18 $[1.05,1.24]$ times the swapped-control norms. This shows a modest extra component on the selected subsets, alongside a large shared component.

Using control-direction sensitivity improves held-out legacy INT4 error prediction by 21.5\% $[12.7,29.4]$. At INT6 the gain is 10.9\% $[-1.2,21.4]$, so the original rule requiring utility at both widths is not met. A similar INT16 gain suggests sensitivity to perturbations generally. Activation survival and the scalar-loss gradient add no clear prediction gain for this vector-error target. The gradient does predict its own loss target moderately ($r=0.63$ at FP, $0.58$ for the INT4 shift); we did not compute a vector-gradient approximation.

Averaging effects across contexts makes preservation look stronger. For legacy INT4, cosine after averaging is higher by 0.126 than the average of context-level cosines. Reports should say which comparison they use.

\paragraph{Fresh text gives a similar INT4 pattern.}
On the six-language Wikipedia panel, INT4 cosine is 0.754, 0.808 and 0.876 for legacy RTN, matched RTN and GPTQ. Control-direction sensitivity improves INT4 prediction by 19\%, 29\% and 30\%. At INT6 it meets the utility rule for both RTN methods, but not GPTQ (3\% $[-14,+17]$), whose error is near the reference scale. GPTQ calibration uses separate articles from the same domain, which may contribute to its advantage.

\section{Discussion and Conclusion}
The study establishes that the selected language-feature groups contribute to next-token prediction in both Gemma sizes. Their effects remain near FP at moderate precision and grow under strong RTN compression. GPTQ better preserves activations and edit effects in the main 2B setting. Many features remain identifiable from output effects even when they fail the activation-survival cutoff. Activation correlation supplies a small, consistent prediction gain.

Other tests set useful limits. The initial selective-vulnerability result is not consistent across quantizers. The selected groups show no clear effect on the comprehension task, and restoring or strengthening them gives limited repair. These findings describe where the proposed interpretation or intervention is supported and where it is not established.

Current SAE research faces incomplete dictionaries, mixed features and explanations that depend on the task. Our controls support causal claims about the specific edits tested. More models and dictionaries would test how widely the findings apply. The completed results already support a measured account of multilingual feature preservation; the pending 9B GPTQ run contributes no evidence here.

\section*{Limitations, Challenges and Future Work}
Most evidence comes from Gemma-2-2B at one layer and one fixed SAE. The 9B RTN extension and narrower Llama check broaden the evidence, but results may differ with other models, layers or dictionaries. Features can mix or split concepts, and large edits can create unusual hidden states. Activity matching and direction controls reduce some differences without matching every feature property. The results apply to the specified edits and outcomes.

Most FLORES analyses reuse examined sentences. Holding out languages or features does not necessarily hold out documents. Intervals condition on the feature groups and other fixed choices. Language tiers also mix script, tokenization, training exposure and competence. Belebele tests one comprehension task, while the external Wikipedia panel has six languages and shares a domain with GPTQ calibration.

The quantization experiment rounds weights during floating-point inference. It does not measure integer-kernel deployment or activation quantization. Calibration and error compensation are not varied independently. Small results can depend on hardware and arithmetic precision, as the correction record shows. Additional independent text, dictionaries and precision comparisons would test broader generalization.
